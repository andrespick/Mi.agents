# Desarrollo

Para una consulta o cambio claro y pequeño, trabaja directamente y verifica lo necesario.
Para una funcionalidad sustancial, carga using-superpowers y sigue:
requirements-engineering-m -> technical-specification-m -> specification-review-m
-> writing-plans. Reutiliza artefactos aprobados. brainstorming solo si falta
definir la intención, antes de requisitos; no generes un segundo diseño después.
Ejecuta el plan por el mecanismo real del programa; no delegues por rutina.
Este rol no fija modelos: hereda la selección del usuario salvo configuración explícita.
