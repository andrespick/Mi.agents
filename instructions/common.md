# Mi.agents: política compartida

Responde en el idioma del usuario. Usa el proceso más pequeño que resuelva la tarea.
La disponibilidad de una skill no obliga a cargarla. Las preguntas, inspecciones
y cambios pequeños y claros no requieren brainstorming, documentos SDD ni subagentes.
Las skills de esta biblioteca son manuales: cárgalas si el usuario las pide o si
selecciona expresamente un rol cuyo flujo las requiere. Reutiliza aprobaciones y
artefactos válidos; no repitas fases. Verifica resultados con evidencia proporcional.

La biblioteca está en {{ROOT}}. Edita sus fuentes y regenera los adaptadores;
no mantengas copias independientes por herramienta. No cargues todas las skills.
Respeta las instrucciones del proyecto y los permisos efectivos del programa.
Los roles, plugins y herramientas disponibles pueden variar entre programas.
Nunca inventes una API de delegación o asegures que ejecutaste pruebas que no corriste.
